## Usage Quest 2.5.0

- **Antigravity CLI(agy) 직접 호출 지원**: agy statusLine 연결 없이도 `agy -p /usage --output-format json` 을 직접 실행해 사용량을 가져옵니다 (agy 1.1.11+ 필요)
  - Antigravity 앱(IDE)이 꺼져 있고 statusLine 저장값도 없을 때 자동으로 agy를 직접 호출하는 폴백으로 동작
  - statusLine 방식(2.4.0)과 병행 지원: statusLine 저장값이 있으면 그것을 우선 사용
- agy 실행 파일 탐색: PATH 탐색 후 `~/.gemini/antigravity-cli/` 등 알려진 경로도 확인
